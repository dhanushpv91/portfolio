# Dhanush — Portfolio

Bilingual personal portfolio (German / English) built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Portfolio content

- About, professional experience and education
- Four selected full-stack projects (design system, banking platform, multi-tenant SaaS, logistics platform)
- German / English language toggle
- GitHub profile: https://github.com/Dhanush-pv

Project cards show descriptions and technology tags. They intentionally do not include achievement bullet lists.
